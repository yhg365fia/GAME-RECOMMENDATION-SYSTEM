# 📅 Day08 — Steam Game Recommendation System (정성적 실험 & 평균 유사도 편향 발견)

## 1. 오늘 한 것 (What I Did)

### 1-1. 정성적 실험(Qualitative Experiment) 설계
정량 지표(Precision/Recall/NDCG)만으로는 "왜 이런 결과가 나오는가"를 알기 어렵다고 판단하여, 실제 게임을 직접 입력해보고 추천 결과를 눈으로 확인하는 정성적 실험을 진행하였다. 실험 카테고리를 아래와 같이 설계하였다(2, 3번은 이번에 직접 진행, 4, 5번은 심화 단계로 보류):

1. 단일 입력 추천 성능
2. 장르 혼합형
4. 니치/마이너 장르 (보류)
5. 인기작 vs 비인기작 (보류)

### 1-2. 실험 1 — 단일 입력 추천 성능
`PUBG: BATTLEGROUNDS`, `Red Dead Redemption 2`, `Party Animals`를 각각 단독으로 입력하여 추천 결과를 직접 확인하고 분석하였다.

- **PUBG**: 배틀로얄/생존 장르로 잘 수렴함을 직접 확인함
- **Red Dead Redemption 2**: 1위로 `Red Dead Online`(동일 세계관)이 나온 것을 통해 시스템이 정상 작동함을 직접 확인. GTA V, MGSV 등 오픈월드 액션 게임들이 함께 추천된 것도 직접 확인함
- **Party Animals**: 장르/인원수/게임 목적은 유사하게 나왔으나, 기대했던 "동물 캐릭터" 테마와 관련된 게임은 결과에 전혀 없었음을 직접 확인함

이 결과들을 놓고 "왜 이렇게 나왔는지" Claude에게 분석을 요청하였고, 다음과 같은 해석을 얻었다: Party Animals의 경우 동물이라는 시각적 테마는 텍스트 메타데이터(Genres/Tags)에 명시되지 않으면 TF-IDF가 원천적으로 포착할 수 없다는 것, PUBG의 경우 "battle"이라는 표면적 단어 매칭 때문일 가능성과 실제 장르적 유사성 때문일 가능성을 구분할 필요가 있다는 것이었다. 다만 이 가설은 1회성 관찰이었고 검증이 필수는 아니라고 판단하여 별도로 코드 검증은 진행하지 않았다.

### 1-3. 실험 2 — 장르 혼합형 (이번 회고의 핵심 발견)
**카드/덱빌딩 게임(`Slay the Spire`, `Balatro`) + 슈팅 게임(`Counter-Strike 2`, `Left 4 Dead 2`)**, 총 4개를 함께 입력하여 결과를 직접 확인하였다.

**결과 (직접 확인)**: Top-10 추천 전부가 카드/덱빌딩/로그라이크/전략 계열이었고, 슈팅/좀비 서바이벌 계열은 단 하나도 포함되지 않았다는 것을 직접 눈으로 확인하였다. `Crypt of the NecroDancer`, `Don't Starve Together` 등 카드게임이 아닌 게임도 일부 섞여 있어 언뜻 "고르게 나왔다"고 착각할 여지가 있었으나, 실제로는 슈팅 계열이 전무하다는 것을 직접 재확인하였다.

### 1-4. 결과 해석 및 가설 수립 (Claude에게 분석 요청)
직접 확인한 결과를 근거로 "왜 이런 쏠림이 발생하는가"에 대한 분석을 Claude에게 요청하였고, 아래 두 가지 가설을 제시받았다.

**가설 1 — 태그 희귀도(IDF) 차이**
카드/덱빌딩 게임의 태그(`deck-building`, `roguelike`, `card game` 등)는 카탈로그 전체에서 등장 빈도가 낮아 TF-IDF의 IDF(역문서빈도) 값이 크고, 그만큼 벡터 내 가중치가 크게 작동했을 가능성이 있다. 반면 슈팅 게임의 태그(`FPS`, `multiplayer`, `action`, `shooter`)는 카탈로그 전반에 흔해 변별력이 낮고, 상대적으로 벡터 영향력이 작았을 것이라는 가설이다.

**가설 2 — 벡터 응집력(크기) 차이**
여러 게임의 벡터를 평균 낼 때, 카드게임 두 개의 벡터가 서로 방향이 비슷하고 크기가 크다면 평균 벡터가 그쪽으로 강하게 끌려갈 수 있다. 반대로 CS2와 L4D2가 서로 얼마나 유사하다고 나오는지에 따라, 슈팅 게임 벡터끼리 서로 상쇄되어 약해졌을 가능성이 있다는 가설이다.

### 1-5. 가설 검증 여부에 대한 판단
"이 가설을 코드로 직접 검증해야 하는가"를 Claude와 논의하였다. 실험 1(PUBG 사례)처럼 1회성 관찰은 검증 없이 가설로만 남겨도 무방하다고 판단했지만, 이번 장르 혼합 쏠림 현상은 **뚜렷하고 완전한 쏠림(슈팅 계열이 단 하나도 없음)**이었고, 이 결론이 향후 하이브리드 모델 설계와 협업 필터링 비교 기준에 직접 영향을 준다는 점에서 최소한의 검증이 필요하다고 판단하였다. 다만 IDF 값을 전부 계산하는 등 학술적 수준의 완전한 검증은 지금 단계에서 과하다고 판단하여, `CS2 단독 입력 시 L4D2가 상위권에 들어오는지`를 확인하는 최소 검증 절차만 다음 단계로 남겨두었다.

## 2. 오늘 배운 것 (What I Learned)

### 2-1. 콘텐츠 기반 추천의 구조적 한계 재확인
TF-IDF 기반 콘텐츠 추천은 텍스트에 명시되지 않은 특성(비주얼 테마, 분위기 등)을 원천적으로 포착할 수 없다는 것을 Party Animals 사례를 통해 직접 확인하였다.

### 2-2. "평균 유사도" 방식의 장르 혼합 취약성
여러 게임을 입력해 평균 유사도를 낼 때, 서로 다른 장르를 균형 있게 반영하지 못하고 한쪽으로 완전히 쏠릴 수 있다는 것을 카드/덱빌딩+슈팅 혼합 실험을 통해 확인하였다. 슈팅 계열이 단 하나도 포함되지 않을 만큼 뚜렷한 쏠림이었다는 점에서, 우연이라기보다 콘텐츠 기반 + 단순 평균 방식의 구조적 특성일 가능성이 높다고 판단하였다.

### 2-3. TF-IDF의 IDF(역문서빈도) 개념을 실전 사례에 적용
"희귀한 단어일수록 가중치가 커진다"는 TF-IDF의 기본 원리가, 실제로 장르 간 쏠림 현상의 원인일 수 있다는 것을 구체적 사례(카드게임의 특화된 태그 vs 슈팅게임의 범용적 태그)에 적용해서 이해하였다.

### 2-4. 검증이 필요한 상황과 필요 없는 상황을 구분하는 기준
1회성 관찰(가설)은 검증 없이 넘어가도 되지만, **결과가 뚜렷하고 극단적이며(예: 특정 장르가 전무함) 향후 설계 판단에 영향을 주는 경우**에는 최소한의 검증이 필요하다는 기준을 세웠다. 다만 그 검증도 "완전한 통계적 증명"이 아니라 "가설의 방향을 확인하는 최소 확인 1회"면 충분하다는 실용적 균형점을 정리하였다.

### 2-5. 정성적 실험과 정량적 평가의 역할 구분
`evaluation.py`의 Precision/Recall/NDCG 같은 정량 지표는 "얼마나 잘 맞았는가"를 수치로 보여주지만, "왜 이렇게 추천되었는가"는 이번처럼 실제 게임을 직접 입력해서 결과를 눈으로 확인하는 정성적 실험이 보완해준다는 것을 체감하였다.
