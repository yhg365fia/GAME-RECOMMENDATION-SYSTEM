# Day 02 - Content-Based Recommendation 데이터 준비

## 📌 오늘 한 일

- 기존 Steam 데이터셋을 분석한 결과 장르(Genres) 정보가 없어 콘텐츠 기반 추천에 적합하지 않다고 판단하였다.
- 새로운 Steam 메타데이터 데이터셋을 탐색하고 전체 컬럼을 분석하였다.
- 콘텐츠 기반 추천에 사용할 메타데이터를 고민한 끝에 `AppID`, `Name`, `Genres`, `Tags`, `Categories`, `About the game` 컬럼을 선정하였다.

### 데이터 로드 과정에서 발생한 문제

새로운 데이터셋을 불러왔을 때 `AppID`, `Name` 등 모든 컬럼이 한 칸씩 밀려 읽히는 문제가 발생하였다.

처음에는 pandas가 첫 번째 컬럼을 인덱스로 인식한 것이라고 생각하여 인덱스를 변경하거나 `reset_index()` 등을 이용해 해결하려고 시도하였다.

이후 데이터 자체가 밀린 것으로 판단하여 DataFrame의 컬럼과 데이터를 직접 한 칸씩 이동시키는 방법도 여러 번 시도하였다.

하지만 수정할수록 다른 컬럼이 사라지거나 데이터가 꼬이는 문제가 발생하여 근본적인 원인이 아니라는 것을 확인하였다.

문제가 `read_csv()` 옵션 때문인지, pandas의 동작 방식 때문인지도 확인해 보았으며, 원본 CSV 파일을 직접 열어 데이터가 정상적으로 저장되어 있는지도 검증하였다.

원본 파일에는 데이터 자체의 문제는 없었지만, 헤더를 자세히 확인한 결과 `Discount,DLC count` 사이의 콤마가 누락되어 `DiscountDLC count` 하나의 컬럼으로 저장되어 있었다.

이 때문에 pandas가 헤더와 데이터의 개수를 다르게 인식하면서 모든 컬럼이 한 칸씩 밀려 읽히는 현상이 발생한 것이었다.

최종적으로 올바른 컬럼명을 직접 정의한 `correct_columns`를 생성하고 `pd.read_csv(names=correct_columns)`를 이용하여 데이터를 정상적으로 불러오는 데 성공하였다.

이후 추천 시스템에 사용할 메타데이터만 추출하고 `fillna("")`를 이용하여 문자열 컬럼의 결측치를 처리하였다.

---

## 💡 오늘 깨달은 점

- AI 프로젝트에서는 모델보다 데이터를 검증하는 과정이 훨씬 오래 걸릴 수 있다.
- 데이터를 억지로 수정하기 전에 반드시 **원인을 먼저 찾아야 한다.**
- 코드가 정상적으로 실행되어도 데이터가 올바르게 읽혔는지는 별개의 문제이다.
- 데이터를 불러온 직후 `shape`, `columns`, `head()`, `info()` 등을 통해 구조를 먼저 확인하는 습관이 중요하다.

---

## 📚 오늘 배운 내용

- 콘텐츠 기반 추천에서는 장르, 태그, 카테고리, 게임 설명과 같은 메타데이터가 핵심 Feature가 된다.
- CSV 헤더의 작은 오타 하나(콤마 하나 누락)도 전체 데이터 구조를 바꿀 수 있다.
- `header`와 `names` 옵션을 이용하여 잘못된 헤더를 수정할 수 있다.
- `fillna("")`를 이용해 문자열 결측치를 처리하면 이후 텍스트 결합과 벡터화 과정에서 오류를 방지할 수 있다.
- 문제를 해결할 때는 **증상을 고치는 것보다 원인을 찾는 것이 더 중요하다.**
